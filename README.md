# Solar Irradiance Prediction PoC

Sahasranshu Technologies

Rodic InfraAI Innovation Challenge 2026

## Objective

Predict next-day hourly Global Horizontal Irradiance (GHI)
for five Indian locations using public weather data.

## Project Structure

- `config/` — site and project configuration
- `data/raw/` — raw API responses
- `data/processed/` — cleaned and aligned datasets
- `data/samples/` — small test datasets
- `src/data/` — data ingestion modules
- `scripts/` — executable pipeline scripts
- `models/` — trained model artifacts
- `reports/` — evaluation and data reports
- `notebooks/` — exploratory analysis
- `tests/` — automated tests
- `solar-irradiance-poc/` — SuryaCast Streamlit Dashboard UI
