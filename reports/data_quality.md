## Known limitations

- ERA5 is a reanalysis built with the ECMWF IFS model, the same model family as the primary NWP input. Absolute errors against ERA5 are optimistic and favour ECMWF over GFS and ICON. Open-Meteo's archive `best_match` returns the ECMWF IFS analysis for recent years rather than ERA5, so the model is pinned.
- Issue time: Forecast for day D is assembled on the evening of D-1 from NWP runs made about 24 hours before each target hour (Open-Meteo `_previous_day1`). For late target hours that run may be published after the evening of D-1, so this approximates rather than exactly reproduces an evening issue time.
